# PyPricing Pipeline

End-to-end insurance pricing pipeline in Python: actuarial models (e.g., GLMs, GAMs, GBMs), feature selection, validation and tariff building with open-source tools.

Status: in planning, development starts January 2027.

## About

Many insurers still rely on commercial software for pricing. Today, however, the open-source Python ecosystem covers the full range of actuarial modelling, from generalized linear and additive models to gradient boosting, together with tools for feature selection, stability testing, validation and parameter fitting.

This project aims to show what a complete, reproducible pricing workflow can look like in Python, from raw policy and claims data to a ready-to-use tariff. The project is developed with the support of Claude Code.

## Planned scope

- Data preparation (policy, exposure and claims data)
- Frequency and severity modelling using different types of models (e.g., GLMs, GAMs, GBMs)
- Feature selection and stability testing
- Model validation and comparison
- Parameter fitting and tariff building
